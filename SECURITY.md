# Security Policy

## Supported Versions

The following table lists the versions of Sentinel Agentic SOC currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

We take the security of Sentinel Agentic SOC seriously. If you believe you have discovered a vulnerability or security flaw in this project:

1. **Do NOT open a public GitHub issue** to report security vulnerabilities.
2. Please report your findings via email directly to the maintainer at **Kyle.Reetz@gmail.com**.
3. Include detailed steps to reproduce the vulnerability, proof-of-concept details (if applicable), and affected component specifications.

### Response Timeline
* **Initial Acknowledgment**: Within 24-48 hours of receipt.
* **Triage & Assessment**: Within 5 business days.
* **Remediation & Patching**: High and Critical severity issues will be prioritized for rapid resolution.

Thank you for helping keep Sentinel Agentic SOC secure.
